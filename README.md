A [Julia](https://julialang.org/) package for handling synthetic aperture radar (SAR) data types.

## Installation

We assume a functional Julia installation.

### Using a Registry (Recommended)

To activate the Matrix Research registry, activate the package prompt in Julia (]) and enter

```
pkg> registry add https://git.matrixresearch.com/Programs/alg/julia/julia_registry
```

This only needs to be done once per Julia installation.
Then, simply add RadarData as you would any other Julia package,

```
pkg> add RadarData
```

If you plan to develop, use

```
pkg> dev RadarData
```
